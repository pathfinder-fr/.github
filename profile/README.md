# Pathfinder-FR

Bienvenue dans l'organisation GitHub de [Pathfinder-FR](https://www.pathfinder-fr.org/), la communauté francophone consacrée au jeu de rôle **Pathfinder**.

Le site propose notamment :

- [le site communautaire](https://www.pathfinder-fr.org/) ;
- [le wiki des règles Pathfinder JdR, première édition](https://www.pathfinder-fr.org/Wiki/Pathfinder-RPG.MainPage.ashx) ;
- [les espaces SRD et les outils associés](https://www.pathfinder-fr.org/srd/).

Cette organisation rassemble les sources, outils, traductions et jeux de données utilisés pour faire vivre ces projets.

## Pathfinder 1

### Wiki et chaîne de contenu

- [`pf1-screwturnwiki`](https://github.com/pathfinder-fr/pf1-screwturnwiki) — export versionné des pages du wiki au format texte ScrewTurn.
- [`pf1-markdown`](https://github.com/pathfinder-fr/pf1-markdown) — contenu Markdown généré pour les sites Pathfinder-FR.
- [`pf1-xml`](https://github.com/pathfinder-fr/pf1-xml) — export XML brut du namespace `Pathfinder-RPG`, destiné à l'analyse et à la réutilisation des données.
- [`WikiXmlExport`](https://github.com/pathfinder-fr/WikiXmlExport) — outil d'export du wiki Pathfinder-FR au format XML.
- [`WikiExportParser`](https://github.com/pathfinder-fr/WikiExportParser) — transformation de l'export wiki en données structurées.

### Données et applications

- [`PathfinderDb.Schema`](https://github.com/pathfinder-fr/PathfinderDb.Schema) — schéma commun pour les données PathfinderDb.
- [`PathfinderDb.WebExplorer`](https://github.com/pathfinder-fr/PathfinderDb.WebExplorer) — application web d'exploration des données PathfinderDb.
- [`XmlToHtml`](https://github.com/pathfinder-fr/XmlToHtml) — génération de contenu HTML à partir de l'export XML.
- [`PathfinderDb`](https://github.com/pathfinder-fr/PathfinderDb) — projet historique de données Pathfinder.

## Pathfinder 2

- [`pf2-data-fr`](https://github.com/pathfinder-fr/pf2-data-fr) — données Pathfinder 2 en français.
- [`pf2-jekyll`](https://github.com/pathfinder-fr/pf2-jekyll) — génération du site SRD Pathfinder 2 avec Jekyll.
- [`pf2-playtest-jekyll`](https://github.com/pathfinder-fr/pf2-playtest-jekyll) — contenu du site de playtest Pathfinder 2.
- [`pf2-flipleaf`](https://github.com/pathfinder-fr/pf2-flipleaf) — projet de rendu FlipLeaf pour Pathfinder 2.
- [`foundryvtt-pathfinder2-fr`](https://github.com/pathfinder-fr/foundryvtt-pathfinder2-fr) — traduction des compendiums Pathfinder 2 pour Foundry VTT.
- [`foundryvtt-pathfinder2e-lang-fr`](https://github.com/pathfinder-fr/foundryvtt-pathfinder2e-lang-fr) — support français du système Pathfinder 2e pour Foundry VTT.

## Outils communautaires

- [`CsvToWikiConverter`](https://github.com/pathfinder-fr/CsvToWikiConverter) — conversion de tableaux CSV vers la syntaxe du wiki.
- [`DiscordAmeiko`](https://github.com/pathfinder-fr/DiscordAmeiko) — bot Discord de la communauté Pathfinder-FR.
- [`Battlemaps`](https://github.com/pathfinder-fr/Battlemaps) — système de battlemaps pour les parties en ligne.

## Contribuer

Les contributions sont les bienvenues. Selon le projet, elles peuvent prendre la forme de corrections du contenu, d'améliorations des outils, de traductions, de signalements de problèmes ou de propositions d'évolution.

Avant de contribuer, consultez le README du repository concerné : chaque projet possède son propre périmètre, ses instructions de développement et ses règles de génération.
